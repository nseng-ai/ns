An **Objective** is a durable Markdown record for work that should survive beyond one branch, one chat, or one PR.

```bash
objective list
```

Objectives hold the thesis, scope, roadmap, decisions, findings, blockers, and completion evidence for multi-session work. They are not hidden agent state or a task database; they are checked-in narrative context that future sessions can read before acting.

## What an Objective is

An Objective is a **durable narrative roadmap record**. It lives under the active Objective root, `.sdl/objectives/`, and uses prose to explain why the work exists, what is in scope, and what has changed.

Objective records are useful when work spans:

- Multiple agent sessions.
- Several branches or PRs.
- A sequence of design, implementation, review, and closure steps.
- Decisions that should remain legible after chat context is gone.

## Updates and closure

A **Semantic Update** records meaningful information: a finding, decision, blocker, changed plan, or completion evidence. It should not be a ceremonial status ping.

A **Tracking Gate** is a read-only check that asks for Objective tracking to be refreshed when branch or worktree evidence suggests meaningful progress has not been recorded.

An **Objective Close** records that the work is complete or intentionally abandoned. Closure is preserved with a lightweight **Closure Marker** so tools can identify closed records without interpreting prose.

## What Objectives are not

Objectives are not workflow controllers, hidden local caches, or issue trackers. They do not replace Git branches, PRs, or Branch Memory. They give humans and agents durable context before choosing the next command.

See the [`objective` tool](/docs/tools/objective) for command details and the [objective skill](/docs/skills/objective) for agent workflow guidance.
