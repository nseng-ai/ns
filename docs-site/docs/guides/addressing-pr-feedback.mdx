title: "Addressing PR feedback"
description: "Use pr-address to download pull-request review state for agent triage."
---

Use `pr-address` when an agent needs structured PR review feedback instead of scraped GitHub pages or copied chat snippets.

```bash
pr-address exec download-feedback --format json
```

## Core loop

1. Download the current PR feedback snapshot.
2. Let the paired skill classify unresolved comments, review bodies, and discussion comments.
3. Make code changes in the branch with normal validation.
4. Post replies or resolve threads only through an explicit confirmed workflow.

## Useful read-only commands

```bash
pr-address exec branch-pr --format json
pr-address exec pr-review-threads --format json
pr-address exec pr-discussion-comments --format json
```

The exact request shape is documented by each command's help. Prefer JSON output so agents can distinguish missing PRs, empty feedback, and command failures.

See [`pr-address`](/docs/tools/pr-address), the [pr-address skill](/docs/skills/pr-address), and [CLI conventions](/docs/concepts/cli-conventions).
