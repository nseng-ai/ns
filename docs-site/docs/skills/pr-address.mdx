title: "pr-address skill"
description: "Agent guidance for downloading and triaging PR review feedback."
---

The `pr-address` skill drives PR feedback triage with stable CLI calls instead of ad-hoc GitHub scraping.

```bash
pr-address exec download-feedback --format json
```

Use it when an agent needs to fetch review comments, review bodies, or discussion comments in a structured form. The current skill workflow is read-only by default: collect feedback, classify what needs attention, and report what should happen next.

## What the skill adds

- Chooses the right PR target for the current branch or an explicit PR number.
- Interprets missing, resolved, automation, and empty feedback cases.
- Keeps GitHub mutations behind explicit confirmation rather than treating replies and resolves as automatic cleanup.

See [`pr-address`](/docs/tools/pr-address) and [Addressing PR feedback](/docs/guides/addressing-pr-feedback).
