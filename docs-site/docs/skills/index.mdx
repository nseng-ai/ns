---
title: "What are skills?"
description: "How public agent skills pair with SDL tools."
---

Skills are agent-facing instructions that call SDL CLIs in a repeatable way. They explain when to use a tool, which commands to call, and how to interpret the result.

```bash
pr-address exec download-feedback --format json
```

## Tool to skill map

| Tool | Skill page | Purpose |
| --- | --- | --- |
| `brmem` | [brmem](/docs/skills/brmem) | Branch-local context storage. |
| `pr-address` | [pr-address](/docs/skills/pr-address) | PR feedback download and triage. |
| `aretro` | [branch-retro](/docs/skills/branch-retro) | Branch/session retrospectives. |
| `objective` | [objective](/docs/skills/objective) | Durable Objective workflows. |

Skills should call hidden `exec` subgroups when the operation is for agents, and humans should read the paired tool page for the public CLI surface.

## Skills are not a second product surface

A skill should document the workflow boundary around a tool: when to collect evidence, when to ask the user, and when a mutation is allowed. It should not copy the entire command manual into an agent prompt.
