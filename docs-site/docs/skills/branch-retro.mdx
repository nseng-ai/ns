---
title: "branch-retro skill"
description: "Turn deterministic branch/session evidence into concise recommendations."
---

The `branch-retro` skill answers one question: what would have made this branch faster, smaller, or higher quality?

```bash
aretro exec collect-evidence --format json
```

The command reports compact observations such as tool usage counts, repeated file reads, failed tool results, and large-output events. The skill then applies semantic judgment and may recommend no change, a small routing note, a follow-up, a CLI affordance, or a documentation update.

## What the skill adds

- Keeps evidence collection deterministic and read-only.
- Separates raw session facts from recommendations.
- Prioritizes actionable changes over a transcript summary.

See [`aretro`](/docs/tools/aretro) and [CLI conventions](/docs/concepts/cli-conventions).
