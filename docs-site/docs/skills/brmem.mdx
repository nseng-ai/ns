title: "brmem skill"
description: "Agent guidance for reading and writing branch-scoped memory."
---

The `brmem` skill tells agents when Branch Memory is the right storage layer and which `brmem` command to call.

```bash
brmem get plan.md
```

Use it for branch-scoped plans, handoffs, and other context that should stay off commits and out of the working tree. Mutating commands such as `put`, `copy`, and `delete` are deliberate workflow actions, not casual scratch writes.

## What the skill adds

- Distinguishes Branch Memory from checked-in Objective records.
- Keeps namespace and key choices explicit.
- Uses read-only commands for inspection unless the workflow has clear mutation intent.
- Routes prompt resolution through hidden `exec` helpers when a skill needs that machine interface.

See [`brmem`](/docs/tools/brmem) and [CLI conventions](/docs/concepts/cli-conventions).
