SDL is a composable toolkit for plan-oriented agentic engineering. It helps humans and coding agents plan work, implement it in isolated environments, and carry context across sessions.

This documentation site is being rebuilt on Next.js, Fumadocs, and `@vercel/geistdocs`. The initial skeleton is intentionally small; the full published corpus will be restored and rewritten as later migration slices land.

## What SDL provides

- **Objectives** for durable narrative roadmaps.
- **Worktree slots** for parallel implementation sessions.
- **Branch Memory and handoffs** for branch-scoped context.
- **PR feedback tooling** for classifying and resolving review feedback.

## Documentation split

Published product documentation lives in this `docs-site/docs/` corpus. The repository-root `docs/` directory remains internal engineering documentation and is not published by this site.
