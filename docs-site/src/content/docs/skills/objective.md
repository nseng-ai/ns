The `objective` skill keeps long-running work grounded in checked-in objective
records rather than chat-only plans.

```bash
objective list
```

Use it when a session needs to understand objective records, choose the next
branch, or close work with evidence. Objectives should remain human-readable
Markdown that future sessions can inspect before acting.

See [objective](/tools/objective/) and [Objectives](/concepts/objectives/).
