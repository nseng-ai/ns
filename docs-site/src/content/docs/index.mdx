asdl is a collection of small CLI tools for branch-local development workflows.
Each tool is installable and usable on its own. Where the umbrella command is
available, the same tools can also be invoked as `asdl <tool>`.

```bash
uv tool install asdl-slots
slot init --size 3
slot checkout feature-x
```

## Start here

1. [Quickstart](/start/quickstart/) — create a `slot` pool and check out your
   first branch-backed worktree.
2. [Installation](/start/installation/) — install individual tools or use the
   umbrella command.
3. [CLI conventions](/concepts/conventions/) — output formats, exit codes, JSON
   envelopes, and hidden `exec` commands.

## Tools

| Tool | Use it for | First command |
| ---- | ---------- | ------------- |
| [`slot`](/tools/slot/) | Parallel branch worktrees. | `slot checkout feature-x` |
| [`brmem`](/tools/brmem/) | Branch-scoped memory for plans and handoffs. | `brmem get plan.md` |
| [`pr-address`](/tools/pr-address/) | Fetching and answering PR review comments. | `pr-address exec get-reviews` |
| [`aretro`](/tools/aretro/) | Collecting deterministic branch retrospective evidence. | `aretro exec collect-evidence` |
| [`objective`](/tools/objective/) | Durable objective records for multi-session work. | `objective list` |
| [`roaster`](/tools/roaster/) | Markdown-driven review harnesses. | `roaster exec format-findings-comment` |
