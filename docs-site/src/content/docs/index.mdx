asdl is one brand containing several co-equal CLI tools. Install one tool for one
job, or compose them under the umbrella `asdl` command when you want a shared
agent-native toolkit.

<CardGrid>
  <Card title="slot">
    Work on many branches at once, each in its own worktree; switching is just
    `cd`.

    `slot checkout feature-x`

    [Read more →](/tools/slot/)
  </Card>

  <Card title="brmem">
    Branch-scoped memory for plans and handoffs, off your commits and out of your
    tree.

    `brmem get plan.md`

    [Read more →](/tools/brmem/)
  </Card>

  <Card title="pr-address">
    Fetch and answer PR review comments end-to-end; reply and resolve threads.

    `pr-address exec get-reviews`

    [Read more →](/tools/pr-address/)
  </Card>

  <Card title="aretro">
    Deterministic branch retrospectives: collect the evidence of what a session
    did.

    `aretro exec collect-evidence`

    [Read more →](/tools/aretro/)
  </Card>

  <Card title="objective">
    Durable, checked-in objectives that structure multi-session work.

    `objective list`

    [Read more →](/tools/objective/)
  </Card>

  <Card title="roaster">
    A markdown-driven code-review harness for running and posting reviewer output.

    `roaster exec format-findings-comment`

    [Read more →](/tools/roaster/)
  </Card>
</CardGrid>

Adopt one tool or the whole suite. The shared [CLI conventions](/concepts/conventions/)
make output formats, exit codes, and hidden agent surfaces predictable, while the
[asdl umbrella](/concepts/umbrella/) explains how standalone CLIs also compose as
`asdl <tool>` subcommands.
