---
title: Objectives
description: Durable, checked-in records for coordinating multi-session, multi-branch work.
sidebar:
  order: 3
---

An **Objective** is a durable Markdown record for work that should survive beyond
one branch, one chat, or one PR.

```bash
objective list
```

Objectives hold the thesis, scope, roadmap, decisions, findings, blockers, and
completion evidence for multi-session work. They are not hidden agent state or a
task database; they are checked-in narrative context that future sessions can
read before acting.
