This guide will show how to keep handoff context attached to a branch without
committing scratch files.

```bash
brmem get handoff.md
```

The full guide will cover when to use Branch Memory, when to commit Markdown
instead, and how handoff skills recover the right context in a future session.

See [brmem](/tools/brmem/) and [CLI conventions](/concepts/conventions/).
