# @nseng-ai/pi-ns-branch-context

Pi host adapter for the [`@nseng-ai/branch-context`](../../../../extensions/branch-context/README.md) ns extension.

This incubating package preserves the `/ns:branch-context:*` and `/ns:plan:*` Pi commands while keeping Pi registration, prompt/status presentation, Saved Plan authoring prompts, Grill activation, and fresh-session orchestration out of the harness-independent Branch Context package. It consumes portable behavior through `@nseng-ai/branch-context/api` and `@nseng-ai/plans/api`, and uses neutral `@nseng-ai/pi-runtime/...` host contracts.

`/ns:plan:save` resolves its repo-editable prompt at `.ns/prompts/branch-context.plans-write.md`; `/ns:plan:grill-and-save` uses the equivalent built-in save contract after structured grilling. Both flows put the exact final Markdown bytes in a temporary regular file, generate an explicit language-model slug, and call the hidden `enriched-plan exec save --slug <slug> --content-file <path> --format json` operation. The caller removes that exact temporary path only after the command exits successfully and returns complete Saved Plan evidence; it retains and reports the path if saving does not succeed. The CLI validates the slug, derives a timestamped `<slug>--YY-MM-DDTHH-mm-ss--<sequence>.md` filename, and publishes those bytes to the current repository/source-branch Local Plan Store. The slug has 3–7 lowercase kebab-case tokens with at least one specific non-generic token and no date-like year token; the timestamp is valid local wall-clock time, and the sequence is a positive integer. Saving does not create a branch, attach Branch Context, or write Branch Memory, and there is no `write_saved_plan_file` tool or Saved Plan session-selection evidence.

Commands that consume a Saved Plan either validate an explicit timestamped path or select the latest timestamped filename for the current repository/source branch. Other filename shapes are not Saved Plans. Latest selection orders the parsed local timestamp and then sequence; local clock rollback, timezone changes, and daylight-saving fallback are accepted limitations. Branch Context resumption session artifacts remain a separate mechanism for reusing an existing implementation branch and Attached Plan.

The package declares its own `pi.extensions` entrypoint and is loaded directly from `.pi/settings.json`, so each ns worktree runs its own package code. The optional ns Slot development profile omits any global copy of this package to prevent duplicate tool registration. No project-local `.pi` discovery adapter is required.
