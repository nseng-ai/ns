# @nseng-ai/pi-ns-gs

## Language

**GS Pi restack router**:
The thin `/ns:gs:restack-resolve` Pi host adapter. It captures one effective resolver skill before
running the fresh ns CLI, accepts only explicit `--downstack` as provider scope, and preserves all
other user text as resolver context. It invokes the skill only for a strictly validated,
process-agreeing Conflict stop.
*Avoid*: conflict editor, restack loop, provider controller, Slot manager, abort command

**GS Pi autobranch router**:
The thin `/ns:gs:autobranch` Pi host adapter. It captures one exact effective recovery skill before mutation, parses only `--slug` as a CLI option, runs a fresh authorized JSON CLI, returns on completion, reports refusal, and hands only strict known-partial or ambiguous evidence to the captured skill.
*Avoid*: mutation engine, replay loop, peer repair, Slot composition

**Trustworthy autobranch recovery handoff**:
A process-agreeing strict negative envelope whose outcome is `known-partial-failure` or `ambiguous-failure`. The exact envelope and preserved user context are inherited; replay, rollback, peer mutation, Slots, push, and GitHub actions are prohibited.
*Avoid*: refusal recovery turn, stderr inference, automatic retry

**Trustworthy conflict handoff**:
A `negative` Clinkr envelope with exit code 1 whose strict GS result is `conflict-stopped`, and whose
process exit code agrees. The inherited structured evidence is authoritative for the resolver turn.
*Avoid*: stderr inference, best-effort JSON, refusal recovery turn
