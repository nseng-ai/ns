# Clinkr Confirmation / Danger-Tier Conformance Audit

Audit basis: ADR 0014 (`docs/adr/0014-clinkr-confirmation-danger-tiers.md`) plus the live Clinkr and command surfaces on branch `clinkr-confirmation-danger-tier-conformance` before this implementation slice.

## Disposition key

- **resolved**: already conforms; no implementation change needed.
- **framework-change**: requires a Clinkr framework/seam change.
- **command-local**: requires a command implementation, option, docs, or test change.
- **parked**: recognized ADR risk, but no current command needs implementation in this slice.

## Expected implementation result

The framework changes should make usage errors a normal handler return path and expose only a minimal interactivity signal on the interaction seam. The command changes should make all prompting destructive commands fail fast when non-interactive and unauthorised, while preserving interactive decline as `ok(cancelled)`, dry-runs as `ok(...)`, and computed-impact refusal/partial-failure as `negative(...)`.
