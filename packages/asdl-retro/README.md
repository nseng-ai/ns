# asdl-retro

`asdl-retro` provides branch retrospective evidence collection.

- Standalone CLI: `branch-retro`
- Skill-facing JSON command: `branch-retro exec collect-evidence --format json`

The CLI returns compact session summaries and deterministic evidence items for retrospective workflows. See [Branch Retrospective Evidence](../../docs/branch-retro.md) for the evidence boundary and design philosophy.
