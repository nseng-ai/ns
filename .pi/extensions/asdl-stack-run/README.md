# ASDL Stack Run Pi Extension

Project-local Pi extension for coordinating ASDL Objective implementation stacks.

The initial slice provides the package skeleton plus deterministic validation helpers for:

- `asdl.stack-plan.v1` stack-plan frontmatter;
- `asdl.stack-slice-ledger.v1` pointer-ledger frontmatter;
- Branch Memory key derivation for plans, ledgers, and handoffs.

Runtime commands and tools are added in later slices of the Objective stack.
