## G — Shim rendering safety

Added `ts/packages/areg/test/unit/source-cli-shim.test.ts`, which invokes the real `ts/scripts/render-cli-shim.py` against the real `ts/scripts/source-cli-shim-template` with `ASDL_TOOL=areg`. The test uses an adversarial canonical checkout path containing spaces, `&`, `|`, backslash, and a single quote; asserts no `@@ASDL_` tokens remain; checks that the canonical checkout assignment is shell-quoted rather than raw; validates the rendered shim with `bash -n`; and executes it from outside a checkout to prove the expected exit-2 diagnostic preserves the exact adversarial path and install hint as data.

No renderer/template change was necessary: the existing `shlex.quote` renderer passed the adversarial shell-parsing proof. A broader shared-shim audit for every installed TypeScript CLI remains outside this Objective.

## K — Version source of truth

`ts/packages/areg/src/cli.ts` now derives exported `VERSION` from `../package.json` via `new URL("../package.json", import.meta.url)` and synchronous `readFileSync`, then validates that the parsed manifest exposes a string `version`. This keeps `buildCli()` synchronous and fits the current Node ESM / pnpm source-runtime layout without TypeScript JSON-import configuration changes.

`ts/packages/areg/test/scenario/cli-shape.test.ts` now asserts `--version` against package metadata rather than an independent `0.1.0` literal, and `ts/packages/areg/test/unit/package-metadata.test.ts` asserts exported `VERSION` matches the manifest. `ts/packages/areg/package.json` is now the areg version source of truth.
