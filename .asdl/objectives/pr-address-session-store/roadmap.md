The contract is recorded in `updates/2026-06-13T150400Z-artifact-taxonomy-and-planning-resolution.md` and reinforced by store-owned lookup work in `updates/2026-06-14T195448Z-payload-store-lookup-boundary.md`.

- [x] Gate artifacts into the store through validation and bootstrap the session.
  - `validate-feedback-classification` persists the validated classification as a session artifact on success when a harness session is configured. Bootstrap is now the harness-owned `HARNESS_SESSION_ID` / `--harness-session-id` contract, not `ASDL_PAYLOAD_SESSION_ID` or caller-side auto-minting.
  - Session-only validation is now the canonical gate: validate resolves the manifest by `--pr-number`, requires exactly one agent-authored classification source, includes `resolved_inputs.manifest`, writes the PR-scoped classification artifact on success, and rejects removed wrapper/manifest/persist flags as unknown options. Evidence: local branch diff against Graphite parent `update-duplicate-abstraction-review-guidance`; full TypeScript check and test passed.
- [~] Migrate planning and read helpers to implicit session resolution.
  - `validate-feedback-classification --pr-number` resolves its manifest from the session and echoes `resolved_inputs.manifest`; `plan-feedback --pr-number` and empty-stdin `stack-feedback-plan` resolve manifest/classification inputs from the session and echo `resolved_inputs`; `read-feedback-detail`, `read-feedback-details`, and `stack-feedback-diff-current` have session-resolved read paths.
  - Remaining work is the compatibility cleanup: `classification-template` still accepts explicit manifest stdin/JSON/file input, `plan-feedback` still accepts wrapper stdin/JSON/file input, `stack-feedback-plan` still accepts explicit payload/prep-reference input, and `stack-feedback-diff-current` still accepts explicit payload/reference input.
- [x] Migrate the mutation flow to explicit artifact references.
  - Single-PR mutation uses the explicit reference contract: `build-resolve-thread-batch-payload --pr-number --batch-id --commit-sha --decisions-file` resolves the latest plan, writes a PR/batch resolve-build artifact for every valid build result, and `resolve-thread-batch --from-build <payload-path>` refuses implicit resolution with `explicit_artifact_required` when the reference is omitted. `resolve-thread-batch` writes a managed resolution-result artifact after successful or partial mutation attempts and rejects non-ready build artifacts before mutation.
  - Stack mutation uses the same boundary: `build-stack-resolve-thread-payloads --batch-id --commit-sha --decisions-file` resolves the latest stack plan from the session, writes one managed per-PR resolve-build artifact for each ready entry, and each ready payload is then applied through `resolve-thread-batch --from-build <payload-path>`.
  - Evidence: local branch diff against Graphite parent `validate-feedback-classification-session-only`, PR #1563, current source/reference inspection for `stack-resolve-thread-payloads.ts` and `skills/pr-address/references/cli-mutation.md`, and full TypeScript check/test passed.
- [x] Shrink lifecycle helpers to agent-owned inputs.
  - `record-batch-checkpoint` now takes PR number, batch id, commit SHA, and an evidence file containing only agent-authored validation and non-thread outcome evidence. It derives `changed_files` from the commit and pulls plan, build payload, and resolution result from the session.
  - `finalize-run --pr-number` now resolves the latest plan, latest final feedback artifact, and latest checkpoint artifact for every planned batch from the session. Missing planned checkpoints are explicit `missing_checkpoint_evidence` errors instead of disappearing.
  - Evidence: local branch diff against Graphite parent `validate-feedback-classification-session-only`, PR #1563, and full TypeScript check/test passed.
- [x] Make compact stdout the default across all exec helpers.
  - Digest on stdout (counts, errors, warnings, `resolved_inputs`, produced artifact reference); full envelope in the session artifact; `--stdout-mode full` escape hatch; process exit code already mirrors envelope `exit_code`.
  - Branch `compact-default-stdout-pr-address-exec-helpers` adds shared compact-output infrastructure (`ts/packages/pr-address/src/stdout-mode.ts`), extends `--stdout-mode compact|full` across collection, planning, mutation, stack, payload, and summary helpers, flips compact to the default, preserves full output through session artifacts, and updates schemas plus CLI reference docs.
  - Follow-up branch `compact-default-stdout/json-schema-fixtures` updates generated JSON schema fixtures and stack orchestration fixtures for the compact-output shapes that initially broke the TypeScript gate.
  - Evidence: local branch diff against Graphite parent `compact-default-stdout-pr-address-exec-helpers`, PR #1571, commit `6858d4c2a`, `pnpm --dir ts/packages/pr-address run test` passed, and `pnpm --dir ts/packages/pr-address run check` passed.
- [~] Remove composed-payload input styles for pipeline-produced artifacts.
  - `--payload-file`/`--payload-json`/stdin composition deleted wherever the input is something the pipeline produced; file input remains only for agent-authored content (decisions, classification answers, validation results, checkpoint evidence).
  - Cutovers landed for `validate-feedback-classification`, `record-batch-checkpoint`, `finalize-run`, `build-resolve-thread-batch-payload`, `build-stack-resolve-thread-payloads`, and `resolve-thread-batch`: removed lifecycle/mutation flags are usage errors, and file input survives only for agent-authored evidence/decision/classification files.
