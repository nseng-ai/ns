# objective-create-steelthread

Create one ns Objective whose whole scope is the thinnest end-to-end slice of a larger ambition: one real task completing through every layer of the real system, with widening explicitly out of scope. The seams between layers are where the surprises live; the thread de-risks integration while the design is still cheap to change. This facade owns the steelthread creation procedure and composes two skills for record mechanics:

- `objective` (umbrella) and `objective-create` (step) own shared vocabulary, slug confirmation and root checks, required headings, Record Frontmatter, the interview, and Verify. Load both first.

## Procedure

1. **Scope the thread.** Through the objective-create interview, pin the one real task and every layer it must cross. The test: completing the task proves every seam of the real system connected. `## Completion Criteria` is the thread validated end-to-end. For a **throwaway steelthread** — validating a design rather than a durable skeleton (standalone scratch code, no reusable infra) — `## Scope` must say explicitly that the artifact is throwaway.
2. **Name the deferred breadth.** `## Non-Goals` names the breadth deliberately deferred to follow-on Objectives or a post-closure rebaseline. `## Parked` holds work already figured out — decided designs, resolved hook points, named follow-on slices — deliberately sequenced post-thread. Parking defers only the implementation, not the thinking: the decisions stand, and the thread must not preclude them.
3. **Choose the shaping.** Two equivalent shapings: reshape the existing record so its scope is the thread (breadth moves to `## Parked`), or split the thread into a Subobjective and promote the original record to an Umbrella holding the overall ambition. Prefer the child split when the parked breadth is substantial enough to need its own coordination.
4. **Verify and stop.** Run objective-create's Verify, plus: completion criteria are the end-to-end thread, `## Non-Goals` names the deferred breadth, parked decisions are recorded not re-litigated, and a throwaway thread's `## Scope` says so.

## Failure modes

- **Breadth creep** — the thread quietly widening into feature work mid-flight; defend by descoping, not by absorbing.
- **Cardboard thread** — stubbing so many layers that completing the one task validates nothing about the real system's seams.

## Layering

Layers well with **autoobjective**: the thread is bounded, concrete, and slice-shaped — a natural autorun target. **Never composes with standing**: a steelthread is bounded by definition. The pattern names the whole record's scope; a steelthread roadmap row inside a broader Objective is a milestone, not a Steelthread Objective.
