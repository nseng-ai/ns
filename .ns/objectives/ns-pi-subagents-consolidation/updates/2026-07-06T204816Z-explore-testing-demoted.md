# Semantic Update: Explore Testing Demoted to Local Fixture

- **Explore testing helpers are no longer package API.** `@nseng-ai/ns-pi-subagents/explore/testing` failed the subpackage rank test: no cross-package or subpath consumers existed, and only the package's own tests used the helpers. The export was removed from `ts/packages/extensions/ns-pi-subagents/package.json` and the README public-export list.
- **Package tests now own the helper locally.** The former `src/explore/testing.ts` helper moved to `test/helpers/explore-testing.ts`, with package tests importing it by relative test-helper paths. The helper still reuses source `explore` contracts and exported `runner-subagents/testing` helpers without exposing a new package subpath.
- **Runner-subagent testing remains exported test support.** `@nseng-ai/ns-pi-subagents/runner-subagents/testing` stays in the package export map because it has a cross-package test consumer and remains vitest-free.
- **Kernel extension workspace helper remains local.** `ts/packages/kernel/test/helpers/extension-workspace.ts` remains a kernel-only test fixture; it is not exported and imports Vitest lifecycle helpers, so it is not package API.
- **Follow-up observations recorded, not acted on.** The audit also found the package's runtime import of `@internal/pi-tools/overlay-kit` despite a devDependency declaration, default-lane kernel tests that still jiti-import inline temp extensions, and the missing `ns.subpackages` declaration that prevents export-map conformance checks from inspecting this package; these belong to other roadmap rows/objectives.
- **Validation evidence.** `pnpm --dir ts/packages/extensions/ns-pi-subagents run test` passed (21 files, 191 tests); `pnpm --dir ts/packages/extensions/ns-pi-subagents run check` passed; `just ts-format-check` and `just ts-lint` passed.
