The real adapter must carry reason-bearing unavailable classification end to end: a negative ancestry answer in a shallow repository and required commits missing from shallow history classify as `incomplete-history` rather than `false`/`missing-object`, complete-repository negatives remain definitive non-forward facts, an unresolved caller-supplied commitish remains `missing-object`, and real shallow-clone integration coverage proves the distinction.
- [ ] Pure reconciliation planner: `deriveReconciliationPlan(facts)` owning candidate selection, whole-corpus validation, path-inclusive `gpr_` identity, transition precedence, classification/schema legality, projection, deterministic artifact ordering, and construction of the complete adapter-neutral frozen semantic apply plan — no gateways; table-driven and property tests (order-independence, plan determinism, at-most-once artifact IDs, and illegal lineage never planning).
  - Proof obligation: exactly one complete semantic plan per fact snapshot, containing all provenance, identities, outcomes, and projections needed for replay without source or registration reinterpretation; moves revise because repository-relative artifact path participates in revision identity, initial full plans one materialization-lifecycle creation event per target artifact, and every later full reconciliation reapplies each planned artifact with a lineage-free repair event regardless of ancestry rather than adding target-drift reads in v1.
