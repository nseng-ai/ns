# Production Architecture and Execution Stack Shaped

## Summary

Execution planning now treats the Brmem and Objectives outcomes on `colocate-brmem-commands-remove-operations` and `colocate-objectives-cli-remove-operations` as golden consumer acceptance baselines. Their route-local filesystem structure, command locality, hidden groups, structural guards, fake-driven scenarios, and observable behavior should be matched or exceeded. The shared Clinkr, Foundation, and SDK prototype machinery beneath those outcomes remains evidence rather than production architecture.

The production direction is one deep `ClinkrApp` module over one private recursively lazy topology and one traversal for execution, help, schema, and completion. Filesystem and narrow programmatic sources adapt into that topology; sources own disjoint subtrees; Commander is fresh invocation materialization rather than another router; context-free and contextful handlers have truthful runtime and type-level call shapes; Clinkr alone owns outcome validation and rendering; raw is an explicit variant; and completion routes through the app topology.

## Objective Impact

The roadmap is now decomposed in dependency order: bless executable README fixtures; establish exact command definitions and outcomes; build topology/source composition; build the single runtime; reconcile Foundation and prove Brmem; rebuild SDK composition; prove Objectives; migrate remaining callers; delete legacy architecture; and qualify packages plus promote the README. Brmem remains the first acceptance consumer and Objectives remains the second, after the SDK seam is closed.

Every `objective-next` prompt for this Objective is now directed by `## Prompt Guidance` to begin with `/ns:plan:grill-and-save`. The planning command must grill a cold-start-safe plan against the durable contract and lessons, place the selected slice in the dependency order, use the golden consumer branch when relevant, minimize and justify PR boundaries, and include deletion-ledger and validation evidence. This guidance shapes prompt serialization only and grants no execution authority.
