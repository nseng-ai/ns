## Boundary and follow-up

- `package.json` declares `legacy` as an API-kind subpackage and `ns.remainder: true`; it passes the rank test by anchoring only quarantined inbound edges.
- Root retains only blocked/shared APIs. No moved symbol is re-exported from root, and `test/app-export-surface.test.ts` checks the aggregate boundary.
- `src/app/**` imports neutral `src/envelope-json-text.ts`, never `/legacy`; blocked owners import qualified APIs through `@nseng-ai/clinkr/legacy` rather than crossing into `src/legacy/**` relatively.
- Before deletion, inventory repository-wide external production and fixture importers, migrate them to `/app`, `/app/testing`, or retained primitives, then remove blocked closure and `/legacy` in dependency order.
