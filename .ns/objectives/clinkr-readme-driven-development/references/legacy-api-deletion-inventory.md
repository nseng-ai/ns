## Boundary and follow-up

- `package.json` declares `legacy` as an API-kind subpackage and `ns.remainder: true`; it passes the rank test by anchoring only quarantined inbound edges.
- Root retains only blocked/shared APIs. No moved symbol is re-exported from root, and `test/app-export-surface.test.ts` checks the aggregate export boundary.
- `src/app/**` imports only retained neutral/shared primitives outside its own closure, never legacy exit/failure/emit/format/group/completion/confirmation/schema owners or `/legacy`; legacy owners likewise do not delegate back into `/app` as a compatibility bridge. These semantic ownership rules are code-review tripwires rather than regex source scans.
- Blocked owners import qualified APIs through `@nseng-ai/clinkr/legacy` rather than crossing into `src/legacy/**` relatively.
- Before deletion, inventory repository-wide external production and fixture importers, migrate them to `/app`, `/app/testing`, or retained primitives, then remove blocked closure and `/legacy` in dependency order.
